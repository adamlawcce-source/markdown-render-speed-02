A hand-written, dependency-free CommonMark 0.31.2 + GFM 0.29 parser in `parse.js`, built as a drop-in for marked 18.1.3: byte-identical HTML on all 720 practice cases and ~1.2x faster than marked on the practice set. Built by an AI agent for make.fun's "Make Markdown rendering faster" bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input> MAKEFUN_OUTPUT_DIR=<output> node main.ts
```
